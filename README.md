# Smart College Timetable Generator

AI-Based Smart College Timetable Generator using Genetic Algorithm.

## Project Description

This project automatically generates a college timetable using Artificial Intelligence.

It uses the Genetic Algorithm to create and optimize possible timetables while considering subjects, teachers, rooms, days and time slots.

## AI Technique

Genetic Algorithm (GA)

## Technologies Used

- Python
- Flask
- SQLite
- NumPy
- Pandas
- Matplotlib
- HTML
- CSS
- JavaScript

## Main Features

- Automatic timetable generation
- Genetic Algorithm based optimization
- Teacher conflict handling
- Room conflict handling
- Subject scheduling
- Timetable visualization
- Web-based interface
