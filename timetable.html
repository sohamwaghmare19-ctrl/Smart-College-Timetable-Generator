🧠 How the AI Works
1. Population: The system creates multiple possible timetable solutions.

2. Fitness Function: Every timetable receives a fitness score based on scheduling quality.

3. Selection: Better timetable solutions are selected for the next generation.

4. Crossover: Two good solutions are combined to create a new timetable.

5. Mutation: Small random changes are introduced to explore better solutions.

6. Optimization: This process continues for {{ generations }} generations and the timetable with the best fitness score is selected.

Result: The final timetable is automatically generated using a Genetic Algorithm instead of manually assigning every lecture.
